# Maison Esthétique Kyiv

Сайт Maison у стилі Apple/iPhone. Усі кнопки запису відкривають власну панель на цій сторінці. Каталог містить 195 послуг у 23 категоріях зі знімка 04.10.2026; справжні фото та контакти збережені.

## Публічний сайт

- Сайт: https://madbod77.github.io/maison-esthetique-kyiv/
- GitHub: https://github.com/madbod77/maison-esthetique-kyiv

Публічна версія використовує GitHub Pages: фото, каталог, пошук, вибір процедур, підсумок і власна панель запису працюють на сторінці Maison. Живий календар, SMS і підтвердження бронювання потребують окремо підключеного сервера з офіційним Altegio API. Поточна публічна версія показує контактний телефон, не надсилає запити на відсутній API та не вигадує бронювання.

Код міститься в гілці `main`, готовий статичний сайт — у `gh-pages`. Для оновлення виконайте `npm run build:pages` і опублікуйте вміст `dist/` у `gh-pages`; джерело GitHub Pages — ця гілка, коренева тека. Значення секретів і `.maison-state/` не публікуйте. Для запуску справжнього запису використовуйте Node-сервер із цього репозиторію на HTTPS-хостингу після підключення API; GitHub Pages виконує лише клієнтський код.

## Запуск

Потрібен Node.js 22+; залежностей немає.

```sh
npm run dev
# http://127.0.0.1:4190/
npm run build
# dist/maison-preview.html та статичні файли
npm test
```

Автономний `maison-preview.html` містить фото, каталог, пошук, мультивибір і підсумок. Живий запис потребує запущеного сервера: статичний HTML сам по собі не створює бронювання.

## Власний запис

Власний інтерфейс: вибір кількох процедур, сума й тривалість, бажаний фахівець, перевірка сумісності, дата, найближчий час, вільні години, контактна форма, згода, SMS-код за правилами салону та підтвердження після відповіді API. Доступні входи за процедурою, фахівцем і часом. Зміна процедур анулює попередній час. Зовнішніх посилань для запису немає.

`booking-model.js` — розрахунки; `booking.js` — стан власної панелі; `app.js` — каталог; `scripts/booking-api.mjs` — серверне підключення до офіційного Altegio API для компанії1328326 і форми1394458. Браузер звертається лише до `/api/booking/*`, ключ ніколи не передається у клієнтський код.

Без офіційного підключення API доступні каталог, розрахунки й вибір бажаного фахівця. Сайт показує недоступність календаря й не вигадує вільних годин або підтвердження. Партнерський API-токен налаштовує адміністратор інтеграції в серверному середовищі як `ALTEGIO_PARTNER_TOKEN`; не додавайте значення в HTML, репозиторій чи чат. Налаштуйте інтеграцію у своєму обліковому записі Altegio; доступ салону і його правила потрібно перевірити під час підключення.

Надсилання запису перевіряє час повторно й захищене від подвійного натискання. Якщо відповідь невизначена, повторне надсилання тієї самої сесії блоковане. Сесії контактної форми тимчасові. Статус операції запису зберігається у приватному журналі `.maison-state/` до звернення до Altegio: невідомий результат лишається заблокованим після перезапуску сервера. Журнал містить статус і номер підтвердження; телефон, процедури й дата представлені HMAC-відбитком. Ключ журналу, runtime-файли та будь-які секрети не входять у ZIP. Не видаляйте журнал, доки невизначені записи не звірено із салоном. `MAISON_STATE_DIR` дозволяє вказати окреме приватне сховище. SMS обмежені за номером, сесією, джерелом і загальним бюджетом компанії. Ліміти джерел діють у межах одного Node-процесу. Перед публічним запуском потрібні HTTPS, офіційний доступ до API, перевірка реально підключеної інтеграції та спільні ліміти для кількох серверів, якщо вони використовуються. Реальні SMS, записи та оплати під час цієї роботи не надсилались. Передоплата/додаткові угоди блокують завершення, якщо інтеграція їх не підтримує.

## Файли і перевірки

- `index.html`, `styles.css` — сторінка і адаптивна панель.
- `assets/`, `data/asset-manifest.json` — справжні фото та їх походження.
- `data/catalog.json`, `data/catalog.js` — каталог зі знімка; не підтвердження актуальних цін.
- `scripts/booking-state.mjs` — приватний стійкий журнал ідемпотентності.
- `tests/booking-api.test.mjs` — локальні контрактні та регресійні перевірки з фіктивним транспортом, без мережевого запису.

Фізичний iPhone і реальний запис після надсилання не перевірялися. Публічна версія має явно відключений живий календар до підключення сервера.
