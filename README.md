## Запуск

Потрібен Node.js 22 або новіший. Залежностей немає.

```sh
npm run dev
# http://127.0.0.1:4190
```

Якщо порт зайнятий:

```sh
MAISON_PORT=52302 npm run dev
```

Сервер за замовчуванням доступний лише на 127.0.0.1. Локальне прев’ю використовує 52302. Статичний реліз для GitHub Pages: https://madbod77.github.io/maison-esthetique-kyiv/. Він містить каталог та анімації, переводить запис до Altegio і пропонує телефон замість надсилання заявок без серверного API.

## Заявки

`POST /api/leads` приймає обов’язкове ім’я, український телефон, згоду, джерело пропозиції, зону або варіант процедури, ідентифікатори вибраних послуг і UUID повторного запиту. Контакти не зберігаються в браузері. На сервері кожна перевірена заявка записується окремим файлом із правами 0600 в `.maison-leads/` (тека 0700). Для іншої приватної теки використовуйте `MAISON_LEADS_DIR`. Тека не обслуговується HTTP, ігнорується Git і не потрапляє до ZIP.

Успіх показується тільки після фактичного запису та отримання квитанції. Повторний запит із тим самим UUID не створює другу заявку, зокрема після перезапуску API. Зміна даних із уже використаним UUID повертає 409. Перевіряються згода, формат телефону, послуги, походження, розмір тіла, honeypot та ліміт запитів. Помилка сховища повертає 503.

Немає автоматичних повідомлень адміністратору, підключення до Tilda, CRM або SMS. Адміністратор може читати приватні JSON-файли на сервері. Для бойового сайту потрібні власний HTTPS Node-сервер, постійне приватне сховище, регламент обробки/видалення заявок і погоджений канал передачі відповідальній людині. Старі ключі Tilda або інші credentials не переносилися й не читалися. Реальних контактів і повідомлень під час QA не використовували.

## Статична копія

```sh
npm run build
npm run build:pages
```

`dist/index.html` — статичний сайт з окремими локальними асетами. `dist/maison-preview.html` — один HTML з інлайн CSS, каталогом, скриптами, фото й шрифтами. Обидві копії чесно блокують надсилання заявок без серверного API та пропонують телефон/Altegio. Node-версія у джерелах має робочий локальний збір. Для хостингу з backend використовуйте джерела і `scripts/serve.mjs`, а не статичний dist.
